# 灰都バトル（マイクラ統合版 4チーム職業PvP）

20の職業から1つを選び、最大4チームで戦う配布マップです。技は近くの敵へ自動で狙いがつくので、PvPが苦手な人でも遊べます。NPCを入れれば1人でも遊べます。

## 遊び方

- 初めて開くと、空の上にロビーが数秒で建ちます
- **北：職業の間** … NPCに話しかけると職業の説明が出て選べます
- **東：チームの床** … 乗った色のチームに入ります（白はおまかせ）
- **西：ミニゲーム** … エアホッケー・スロット
- **南：ステージの門** … 「滅びた世界」「天空の浮島」の門を調べて、モード → NPCの人数（なし／1チーム2〜4人）を選ぶと出撃（各ステージ初回だけ1分ほど生成）
- 最初に入った人に「管理の書」が渡されます（チーム数・制限時間1〜7分・残機・NPCの人数と強さ・アイテムチェスト）

### 操作

| ホットバー | 使い方 |
|---|---|
| 武器 | ふつうに攻撃 |
| 戦技の書 | 使うと戦技。**スニークで4つの技を切り替え**。MPを使う |
| 絶技の結晶 | ゲージが100%で職業ごとの必殺技 |
| 休憩 | 動かない間、5秒ごとにHP+3・MP+2 |
| ローリング | 前転で回避（ぎりぎりで避けるとジャスト回避）。空中で壁に向かって使うと**壁蹴り**、壁がなければ空中ダッシュ |

試合中はHP・MPが自然には回復しません。回復はアイテム・奪う技・味方の技・自動回復の特性・休憩だけです。

## 職業（20）

| 括り | 職業 | 最大MP |
|---|---|---|
| 物理アタッカー | 剣士・狂戦士・暗殺者・弓使い | 80 |
| 魔法アタッカー | 魔導士・雷術師・召喚士・錬金術師 | 120 |
| バッファー | 吟遊詩人・守護騎士・重騎士・軍師 | 100 |
| ヒーラー | 僧侶・水術師・森の癒し手・薬師 | 110 |
| デバッファー | 呪術師・氷結士・罠師・幻術師 | 100 |

属性（ホムラ・ミナモ・ツララ・イカヅチ・ハヤテ・イワオ・コノハ・クロガネ・ヒジリ・トコヤミ）の相性や、物理・射撃・魔法への得意不得意があります。

## ステージ（2）

- **滅びた世界**：崩れたビルが並ぶ灰色の街。道路にジャンプ台
- **天空の浮島**：空に浮かぶ島を橋でつないだステージ。落ちたら場外

## モード（14）

占領ポイント／残機制（爆発で地形が壊れる・試合後に元通り）／総合ポイント／コア破壊／キング防衛／宝運び／王冠争奪／バトルロイヤル／ボス討伐レース／討伐レース（PvPなし）／コイン収集／賞金首／ウェーブ協力／トレーニング（1人で技の練習）
